A simple ToDo List / Task Management web application built with HTML, CSS, and JavaScript. This app allows you to manage tasks in different stages: Draft, In Progress, Done, and Canceled.

Features

- Add new tasks with Title, Description, and Status.

- Popup form for adding tasks in a structured way.
  
- Tasks can have statuses: `Draft`, `In Progress`, `Done`, `Canceled`.
  
- Tasks are saved in LocalStorage, so they remain even after refreshing the page.
  
- Simple, responsive, and user-friendly interface.

 How to Use

 Open `index.html` in your browser.
 
 Click **Add** in the Draft column to create a new task.
 
 Fill in **Title**, **Description**, and select **Status**.
 
 Click **Save** to add the task to the corresponding column.
 
 Tasks will be saved automatically and will persist on page reload.

 Technologies Used

 HTML5
CSS3
JavaScript (ES6)
LocalStorage for persistent storage
